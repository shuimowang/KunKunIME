## Android 0.1.0

困困输入法安卓正式版。最低 Android 16（API 36），手机安装包仅支持 ARM64。

### 长按空格语音输入

- 默认按住空格说话，松手结束识别，上滑后松手取消。短按空格仍然选词或输入空格；长按开始前的左右滑动仍可移动光标。
- 首次使用先选择识别方式并授权麦克风。回到原输入框后，再次长按才开始录音；拒绝授权不影响普通打字。
- 默认优先设备端识别。手机缺少服务或所需语言模型时会明确提示；只有用户明确允许后，才使用可能联网处理声音的系统语音服务，其数据处理由服务提供者管理。
- 识别中显示状态，只把最终文字输入本次开始录音的输入框。取消、切换输入框或收起键盘后丢弃迟到结果；密码框禁用语音，无痕模式仅允许设备端识别。困困输入法不保存录音。

语音能力依赖手机提供的 Android 识别服务及语言模型；应用不包含豆包的程序、模型或服务。已有全拼、双拼、英语补全、候选展开、数字、符号、表情和剪贴板功能继续保留。

### 常用语

剪贴板面板新增「常用语」页，首次提供 4 条例句。点「+」新增，长按可编辑、移到顶部或删除；点选只填入当前输入框，不自动发送消息。

常用语与剪贴板历史分开保存，最多 100 条、每条最多 2000 字。启用系统备份时，常用语会随应用数据备份和恢复，剪贴板历史仍不进入备份。

### 应用内更新

在「关于 → 应用更新」主动点击「检查更新」，只查看本仓的安卓正式版；有新版时确认下载，可查看进度或取消。下载后校验 APK 的 SHA-256、包名、版本及签名，确认签名与已安装应用一致且版本更新后，才交给系统安装界面。未知来源授权和最终安装由用户确认，不会静默安装。

不会在后台自动检查更新，检查和下载不上传输入内容、个人词库或录音。下载使用应用缓存，不需要存储权限。

### 下载与升级

下载 `KunKunIME-Android-0.1.0-arm64-v8a.apk`。正式版使用递增的 `versionCode = 5` 与既有固定证书，已安装签名一致的 preview.2、preview.3 或 preview.4 可直接覆盖升级，保留设置与词库。preview.1 使用临时证书，需先导出个人词库，再卸载旧版、安装并导回。

首次安装打开「困困输入法」，按「启用 → 选择 → 试用」操作；首次词库准备仍需时间。长按空格的其他动作仍可在按键设置中选择，已有明确选择会保留。

### 构建与验证范围

使用非调试 release APK，启用 R8 代码与资源压缩；分发前核对固定签名、16 KiB 对齐和重签前后的应用内容一致。自动检查包括真实拼音核心、语音生命周期、空格手势、常用语操作和 API 36 模拟器中的实际输入流程。debug 与 release 各运行受控识别服务的真实 IPC 测试，检查长按与松手、最终结果上屏、取消后迟到结果不串框；固定结果的服务只在测试 APK 中。模拟器没有真实语音输入，因此这些检查不代表对具体手机或中文语音准确率的测量。

本应用申请振动、麦克风、网络与请求安装应用权限；网络仅用于用户主动检查和下载 GitHub 更新，安装由系统确认。系统语音服务可能联网的行为在首次设置时说明并由用户决定。此版仍没有九键拼音或两端自动同步。

`SHA256SUMS.txt` 对应实际分发附件；`Cargo-sources.zip` 包含锁定版本的第三方 Rust 依赖源码。本仓代码与本地补丁见此标签的 Source code 归档，第三方材料的来源、许可随 APK 和仓库提供。
