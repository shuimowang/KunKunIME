## Android 0.1.1

增加应用内离线语音识别。最低 Android 16（API 36），手机安装包仅支持 ARM64；电脑版继续独立构建与发行。

### 下载语音包，在手机本地识别

- 进入「设置 → 语音输入」，下载 **SenseVoiceSmall INT8** 语音包；下载完成并通过校验后，点「使用离线语音」，按系统提示授权麦克风。
- 语音包下载约 **155.5 MiB**，安装后约 **228.5 MiB**；安装时请至少预留 **450 MiB** 可用空间。模型独立保存，正常覆盖升级应用会保留已下载的同版本语音包。
- 沿用长按空格说话、松手结束、上滑取消。模型首次加载时需要先等待准备完成，再开始说话；松手后由手机处理整句文字。准备期间松手或取消，不会迟到开启麦克风。
- 使用 sherpa-onnx `v2.0.3` 与固定版本的 SenseVoiceSmall INT8 `2024-07-17`。中文和英文为主要使用场景，模型还支持粤语、日语、韩语；实际速度和准确度取决于手机、语种、口音及录音环境。
- 单次语音最长 60 秒。长录音可能分成不超过 15 秒的片段识别后拼接，分段处上下文不足可能影响文字或标点。此版采用松手后识别，不承诺边说边出字。
- 下载可查看进度、取消、失败重试；校验成功后才可使用，已安装的语音包也可从设置中删除。删除不会自动切换到联网识别。

### 数据与兼容

语音包只有在用户点击下载时才从固定的 GitHub 发行附件获取，并核对大小与 SHA-256。模型保存在应用私有的 `noBackupFilesDir/offline-voice` 目录，不进入系统备份，换机后需重新下载。离线识别时音频只在手机内存中临时处理，不访问网络、不保存录音，也不上传输入内容、个人词库或常用语。

应用内离线语音不要求手机安装 Android 系统识别服务。原来明确选择的系统识别方式继续保留，升级和下载模型均不会擅自替换用户选择。若想切换到新引擎，请在语音设置中点「使用离线语音」。可能联网的系统语音服务仍需用户明确允许，本版本没有新增商业云端识别 API。

取消、收起键盘或切换输入框会结束本次录音并丢弃迟到结果；只把最终文字写入本次开始输入的编辑框，不自动发送。密码框禁用语音，无痕模式仅允许本地识别。

### 下载与升级

下载 `KunKunIME-Android-0.1.1-arm64-v8a.apk`。`versionCode = 6`，沿用既有固定签名。已安装签名一致的 `0.1.0` 或 preview.2 / preview.3 / preview.4 可直接覆盖安装，保留设置、个人词库与常用语。`0.1.0` 用户也可以从「关于 → 应用更新」检查、下载并安装新版。

preview.1 使用临时证书，不能直接覆盖；需先导出个人词库，再卸载旧版、安装新版并导回。卸载会删除尚未导出的应用数据。

### 构建与验证范围

本次 [Android 构建与检查](https://github.com/shuimowang/KunKunIME/actions/runs/45936254882) 已全部通过，发布标签固定到实际测试的源码提交 `73246fec9b84e9885a22cef84c957b129f055d1f`：

- 真实拼音与英文核心绑定检查；59 个测试类中的 **430 项 JVM 单元测试**，失败、错误与跳过均为 0。
- API 36 模拟器上的 **18 项 debug 基础设备测试**；debug 与非调试 release 各通过真实输入法、系统语音 IPC、离线语音 3 项完整流程检查。
- 两种构建均使用实际 CPU/JNI 引擎转写固定中文与英文样本，并验证真实 `AudioRecord` 启动、上滑取消后停止、不重启、不写入编辑框，且没有调用受控的系统语音识别服务。
- 手机 ARM64 与模拟器 x86_64 安装包的版本、代码、资源及词库一致；正式包启用 R8 压缩，不含调试标记、测试模型或测试录音，原生库通过 16 KiB 兼容性检查。

固定样例推理和模拟器检查不等同于对具体手机麦克风、噪声环境或中文准确率的全面测量。本版的五语种支持来自模型本身，本次真实样本验证覆盖中文与英文。

分发 APK 已核对既有固定签名、16 KiB ZIP 对齐与重签前后的全部应用内容一致；`SHA256SUMS.txt` 对应实际分发附件，`Cargo-sources.zip` 提供锁定版本的 Rust 依赖源码。源码对应本发布标签。

sherpa-onnx 引擎为 Apache-2.0；SenseVoice 模型权重使用 **FunASR Model Open Source License Agreement v1.1**，保留模型名称、作者及来源。第三方材料与许可说明随 APK 和仓库提供；语音模型作为按需下载的独立资源提供。
