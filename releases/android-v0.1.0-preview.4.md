## Android 0.1.0-preview.4

这是面向个人试用的安卓预览版，最低 Android 16（API 36），手机包仅支持 ARM64。

- 改用非 debug 的 `release` APK，启用代码和资源压缩；发行 APK 不包含可等待的冷启动测试门闩。
- 保留拼音、双拼、英文补全、候选展开、数字页、符号、表情和剪贴板，以及之前的底部避让和配置、图标预载优化。
- 在模拟器中对实际 release APK 验证中文候选上屏、英文、密码、数字输入及键盘隐藏后恢复。debug 构建单独验证初始化期间暂存按键和切换输入框，不把该门闩测试作为 release 的测试结论。
- 手机包和模拟器包分别验证架构、清单和共享代码/资源/词库。分发手机包使用既有固定私钥签名，并核对签名、16 KiB 对齐和签名前后载荷一致。

### 下载与升级

下载 ARM64 APK。已安装固定签名的 preview.2 或 preview.3 时可以直接覆盖安装，保留设置和词库；preview.1 使用不同临时签名，需先导出个人词库，再卸载旧版、安装并导回。

首次安装打开「困困输入法」，按「启用 → 选择 → 试用」引导操作。首次词库准备仍需时间；本次设备验证在 API 36 模拟器进行，不代表已经覆盖所有手机真机。

本应用不申请网络权限。此版仍没有九键拼音、内置语音识别或两端自动同步。

`SHA256SUMS.txt` 对应实际分发附件；`Cargo-sources.zip` 包含锁定版本的第三方 Rust 依赖源码，本仓代码与本地补丁见此标签的 Source code 归档。第三方材料的来源、许可随 APK 和仓库提供。
