## Windows 0.1.10

- 修复拼音候选窗可能被置顶窗口遮挡的问题；显示和刷新时恢复候选窗层级，同时保持输入焦点和自身弹窗的正确顺序。
- 使用 Cargo `release` 配置构建 Windows 程序；64 位和 32 位 TSF 组件也使用 Release 配置。
- 程序、设置及定制清单的版本统一为 0.1.10。
- 发行前运行组件加载、输入协议、拼音/英文、设置和候选窗回归检查；附件发布前核对 SHA-256。

### 下载与安装

下载 `KunKunIME-0.1.10-Windows-x64.zip`，将整个「困困输入法」文件夹解压到固定位置。更新时先退出已有程序；全新安装打开 `KunKunIME.exe`，在设置中注册输入法，再用 Win + 空格切换。

`SHA256SUMS.txt` 提供两个 ZIP 的校验值。`Cargo-sources.zip` 包含锁定版本的第三方 Rust 依赖原始源码；本仓代码和本地补丁源码由本标签的 Source code 归档提供。数据和第三方材料的来源、许可随程序分发。

安卓使用独立的 `android-v…` 预览标签和 APK，不包含在 Windows 压缩包中。
