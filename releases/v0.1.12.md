## Windows 0.1.12

- **检查更新**。打开「设置 → 关于」会自动查询困困输入法的 Windows 正式版，结果直接显示在页内。有新版时点「查看新版」可查看发布说明或下载 ZIP。页首的「困困输入法 GitHub 主页」直达本项目源码。
- **卸载困困输入法**。在「设置 → 关于」打开卸载向导。已注册的安装也可以从 Windows「设置 → 应用 → 已安装的应用」进入。默认保留个人词库与设置，勾选后可一并清除。向导识别本次安装的文件和系统注册，保留自行添加或修改过的文件，并提示外部自定义数据目录的位置。

### 下载和升级

下载 `KunKunIME-0.1.12-Windows-x64.zip`。升级已有安装时，退出困困输入法，把完整压缩包解压到原安装位置，再打开程序。请将新版的 `uninstall-manifest.json` 与 `KunKunIME.exe` 放在一起。从公开 v0.1.11 升级可直接使用本页的 ZIP，之后即可在软件内检查新版本。

这次新增功能位于主程序。从 v0.1.11 升级这两项功能只需重新打开困困输入法，无需重新注册输入法或重启 Windows。全新安装请打开 `KunKunIME.exe`，在设置中注册后按 Win + 空格切换。

`SHA256SUMS.txt` 提供 Windows 程序包与 Cargo 依赖源码包的 SHA-256 校验值。
