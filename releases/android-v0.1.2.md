## Android 0.1.2

**从 0.1.1 升级需要一次重新安装。** 0.1.2 启用新的发行签名。旧版的「检查更新」能找到本版，Android 签名校验会拦截直接覆盖安装。请先在词库页点「导出词库」，将常用方案的词库分别存到手机的「下载」目录，另存需要的常用语。然后从本次 GitHub 发行下载 APK，卸载旧版、安装新版，重新启用键盘并点「导入词库」。卸载会清除应用设置、常用语及离线语音包。以后的正式版会沿用 0.1.2 的签名。

### 在「关于」查看更新

从 0.1.2 起，打开「关于」就会查询安卓正式版，并在本页显示结果。可在「应用更新」中手动重试。日常打字不会触发版本检查。下载 APK 和安装仍由你确认。

### 拼音编辑和个人词库

- 修复拼音组词时移动光标的位置。编辑含扩展汉字、组合表情的文本时，方向键和滑动退格按可见字符定位。
- 在个人词库搜索时显示匹配数。删除一条词会保留同码的其他候选。清除搜索后才可清空整个方案的个人词库。
- 添加词条时旋转屏幕，之前填写的编码和词语会保留。
- 「试一试」中的密码输入会遮罩显示，完成或切换场景时会清空。试打内容不写入系统日志。「关于」中可直接打开困困输入法的 GitHub 主页。

### 首次安装

下载 `KunKunIME-Android-0.1.2-arm64-v8a.apk`，适用于 **Android 16（API 36）及以上的 ARM64 手机**。`versionCode` 为 7。`SHA256SUMS.txt` 提供附件校验值，`Cargo-sources.zip` 提供锁定版本的 Rust 依赖源码。
