# 困困输入法

把完整发行目录解压到固定位置，双击 **KunKunIME.exe**。首次点击 **注册输入法** 并确认管理员授权，然后按 **Win + 空格** 选择 **困困输入法**。设置改动会自动保存，关窗后输入服务继续运行。

- **拼音**。默认使用全拼，小鹤双拼可在“输入方案”中切换。输入拼音后用空格选首选，或按数字选择候选。
- **英语直出**。单点左或右 **Shift** 切换中英文。适合输入大小写英文、代码、网址。
- **英文补全**。在输入方案中选择“英文补全”。**Ctrl + Shift + E** 默认循环已启用的方案。拼音状态也可显示英文候选。
- **词库**。打开“词库管理”可批量导入、勾选后一次删除。内置“王者荣耀人名”词库可在“词库列表”中查看和关闭。

个人设置与词库存放在 `%APPDATA%\KunKunIME`，本地缓存和日志在 `%LOCALAPPDATA%\KunKunIME`。请保留程序同目录的两个 DLL 及数据目录。需要取消系统注册时，请参阅随包的[卸载说明](卸载Windows输入法注册.md)。
