# 困困输入法

把完整发行目录解压到固定位置，双击 **KunKunIME.exe**。首次点击 **注册输入法** 并确认管理员授权，然后按 **Win + 空格** 选择 **困困输入法**。设置改动会自动保存，关窗后输入服务继续运行。

- **拼音**。默认使用全拼，小鹤双拼可在“输入方案”中切换。输入拼音后用空格选首选，或按数字选择候选。中文标点状态下直接按分号键可输入 `；`。拼音候选还在屏幕上时，按分号键会将当前候选与 `；` 一起上屏。
- **英语直出**。单点左或右 **Shift** 切换中英文。适合输入大小写英文、代码、网址。
- **英文补全**。在输入方案中选择“英文补全”。**Ctrl + Shift + E** 默认循环已启用的方案。拼音状态也可显示英文候选。
- **词库**。点击左侧的“词库管理”管理词条，或直接点击“输入规则”“按键设置”等切换页面。左侧主导航保持在原位。也可以用原来的 Quicker 动作直接进入拼音主词库。词库支持批量导入和勾选后一次删除。内置“王者荣耀人名”词库可在“词库列表”中查看和关闭。

**邮箱和网址**。打开“词库管理 → 输入补全”，点“邮箱后缀”或“常用网址”，在同页开关输入模式、添加或编辑条目。“输入规则 → 网址/邮箱输入”有直达这两页的按钮。粘贴完整邮箱时只保存 @ 后面的域名。开启对应模式后，在拼音中文状态下，连续打 `demo@gm` 可选 `demo@gmail.com`；输入 `www.` 或 `http` 等前缀可进入网址模式。空格选候选，回车输入原文。切到英文直出时，按键直接交给当前应用。

**其他补全**。同一组里的“快捷输入历史”可以添加常用文本。使用快捷输入时，先在“输入规则 → 快捷输入”设置触发键。

个人设置与词库存放在 `%APPDATA%\KunKunIME`，本地缓存和日志在 `%LOCALAPPDATA%\KunKunIME`。请保留程序同目录的两个 DLL 及数据目录。需要取消系统注册时，请参阅随包的[卸载说明](卸载Windows输入法注册.md)。

**Agent 接入**。在本机 MCP 客户端中选择标准输入输出（stdio），选择程序 `KunKunIME.exe`，启动参数填写 `mcp`。[接入步骤与工具清单](MCP.md)
